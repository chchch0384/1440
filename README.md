# 1440

一天一分鐘的瞬間收集計畫。每天挑一個值得記住的瞬間，拍一張，那一分鐘的格子就亮起來。把 00:00 到 23:59 的 1440 格慢慢收滿。

App 網址：https://chchch0384.github.io/1440/

## 怎麼運作

主畫面一顆「1440」圖示，打開就是拍照畫面。按「拍」會叫出 iPhone 原生後置相機，拍完按「使用照片」，照片回到 App 的那一分鐘就是它的格子。照片先存在手機暫存，上傳到你自己的 Google Drive 成功後才刪掉。回顧有兩層：總覽（24 欄 × 60 列的 1440 格拼貼）和小時書（24 頁，一頁 60 張）。

```
iPhone 主畫面 App「1440」（GitHub Pages）
  按「拍」→ 原生相機 → 照片回來 → canvas 縮圖 → 上傳
        │
        ▼
Google Apps Script（收件員：檢查密鑰、判斷第一張、標記作弊）
        ├──► Google Drive 1440/photos、1440/thumbs
        └──► Google 試算表 1440-紀錄
```

## 第一次設定

### Google 這一邊

1. 在 Google Drive 新增一份 Google 試算表，命名為 `1440-紀錄`
2. 試算表選單「擴充功能 → Apps Script」，把 [apps-script/Code.gs](apps-script/Code.gs) 的內容全部貼上，取代原本的程式碼，存檔
3. 上方函式選單選 `setup`，按「執行」。第一次會要求授權：選你的帳號 →「進階」→「前往 1440（不安全）」→ 允許。這支程式是你自己貼進自己帳號的，警告是 Google 對所有未上架程式的固定說法
4. 執行完，試算表會多一個「設定」分頁，密鑰已經填好；Drive 也會多出 `1440/photos` 和 `1440/thumbs`
5. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」→ 執行身分「我」→ 誰可以存取「所有人」→ 部署
6. 點部署完成畫面上的網頁應用程式網址，看到「1440 收件員運作中」就成功了。這一步同時會把網址寫回試算表
7. 回到試算表「設定」分頁，B7 就是專屬連結，存到 iPhone「密碼」App 或備忘錄

### iPhone 這一邊

主畫面 App 和 Safari 的儲存空間是分開的，所以順序要對：

1. 用 Safari 打開 https://chchch0384.github.io/1440/
2. 分享 → 加入主畫面
3. 從主畫面的「1440」圖示打開，會看到「貼上專屬連結」的畫面
4. 貼上專屬連結 → 儲存並測試連線 → 連上了就完成

## 每天

- 還沒拍：打開就是拍照畫面，上面是現在時間和這分鐘的狀態（🟢 空的 / ⚪ 已擁有）。拍 → 快門 → 使用照片，結束。
- 那格已擁有：App 問一句「還是要記錄嗎？」，還是要就存成額外照片。
- 已經拍過：打開只看到今天的照片，底下有「總覽」「小時書」，角落一顆小小的「作弊：再拍一張」。
- 沒網路或上傳失敗：照片留在手機，畫面顯示「待上傳」，下次打開自動續傳。還沒傳成功前長按照片可以先存進相簿。

## 更新收件員程式碼

每次 Code.gs 有新版：

1. 把新的 [apps-script/Code.gs](apps-script/Code.gs) 全部貼上取代，存檔
2. 部署 → 管理部署作業 → 按鉛筆 → 版本選「新版本」→ 部署

網址不會變，專屬連結也不用重貼。只存檔、沒發新版本的話，網址跑的還是舊程式碼。

## 出事了怎麼辦

- 密鑰外流：Apps Script 編輯器執行 `rotateKey()`，回試算表「設定」分頁重新複製專屬連結，在 App 總覽頁最下面「重新設定專屬連結」貼上。
- 試算表壞了或誤刪：執行 `rebuildFromFilenames()`，會從 Drive 的 photos/ 檔名重建整份紀錄。
- 換手機：加入主畫面 → 貼專屬連結，縮圖會重新抓一次。
